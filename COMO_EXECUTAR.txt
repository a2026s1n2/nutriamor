NutriAmor-Web — como executar
=============================

1) Criar ambiente virtual e instalar dependências:
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt

2) Configurar .env (copiar de .env.example):
   - Para testar sem PostgreSQL: USE_SQLITE=True
   - Para PostgreSQL: USE_SQLITE=False e DATABASE_URL=postgres://utilizador:senha@host:5432/nutriamor

3) Migrações e dados iniciais:
   python manage.py migrate
   python manage.py seed_base
   python manage.py createsuperuser   (e-mail, nome, perfil no admin depois)

4) Servidor:
   python manage.py runserver

5) SQL de referência (revisão DBA): database/schema.sql

6) Importar NF-e por XML: menu «Importar XML NF-e» ou Estoque → DANFEs → «Importar XML». Os dados ficam em cache 1 hora (revisão antes de gravar).

Perfil CONSULTA: apenas leitura nas telas de criação/edição (mixin EscritaNecessariaMixin).

7) Docker (PostgreSQL + Gunicorn)
   - Copie .env.docker.example para .env e defina SECRET_KEY e ALLOWED_HOSTS (domínio ou IP do servidor).
   - Stack completo: docker compose --profile full up --build
   - Só base de dados (Django na máquina): docker compose up -d db
   - Primeira vez no contentor: docker compose --profile full run --rm web python manage.py seed_base
   - Superutilizador: docker compose --profile full run --rm web python manage.py createsuperuser

8) VPS Ubuntu 24.04 — clone e deploy (passo a passo completo)
   - Repositório: git clone https://github.com/a2026s1n2/nutriamor.git
   - Ver ficheiro: deploy/VPS-instalar-desde-github.txt
   - Resumo: clonar em /opt/nutriamor-web, bash deploy/install-docker-ubuntu24.sh, .env, docker compose --profile full up -d --build
   - Testar: http://SEU_IP:8000
   - Firewall (opcional): sudo ufw allow OpenSSH && sudo ufw allow 8000/tcp && sudo ufw enable
   - Produção: Nginx/Caddy na porta 443; não exponha root por palavra-passe.

9) Domínio e subdomínio (ex.: nutriamor.cienciadedadosunivesp.app.br)
   DNS (no painel do domínio cienciadedadosunivesp.app.br):
   - Tipo A, nome "nutriamor", valor = IP público da VPS (ou CNAME se o registador permitir apontar para o host raiz).
   - Propagação pode levar de minutos a algumas horas.
   No servidor Ubuntu:
   - sudo apt install -y nginx
   - Copie deploy/nginx-nutriamor-subdominio.conf para /etc/nginx/sites-available/nutriamor e ajuste server_name se necessário.
   - sudo ln -sf /etc/nginx/sites-available/nutriamor /etc/nginx/sites-enabled/
   - sudo nginx -t && sudo systemctl reload nginx
   - sudo ufw allow 'Nginx Full'   (ou allow 80,443/tcp)
   - SSL: sudo apt install -y certbot python3-certbot-nginx
         sudo certbot --nginx -d nutriamor.cienciadedadosunivesp.app.br
   No .env da app (Docker):
   - ALLOWED_HOSTS=nutriamor.cienciadedadosunivesp.app.br,127.0.0.1
   - CSRF_TRUSTED_ORIGINS=https://nutriamor.cienciadedadosunivesp.app.br
   - BEHIND_HTTPS_PROXY=True
   - Reinicie: docker compose --profile full up -d --build
   Aceda: https://nutriamor.cienciadedadosunivesp.app.br
